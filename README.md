Smart Water Level Indicator
This project implements a digital logic-based water level monitoring system.
It uses combinational logic circuits to detect water levels and display them with LED indicators and a buzzer,making it easy to monitor the status of a water tank.

Components Required:
.Logic gate ICs (AND, OR, NOT, etc.)
.Water level sensors/probes
.LEDs for indication
.Buzzer for audio alert
.Resistors and connecting wires
.Breadboard or PCB

Features:
Monitors multiple water levels using sensors
LED indicators show tank status (empty, half, full, etc.)
Buzzer alert when the tank is full or critically low
Simple, low-cost design using basic logic gates
Easy to assemble and test

Setup:
Connect sensors at different water levels in the tank.
Wire the sensors to logic gate circuits.
Connect outputs to LEDs and buzzer for clear visualization.
Test by filling the tank and observing LED + buzzer responses
